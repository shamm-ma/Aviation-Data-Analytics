# Aviation Analytics Portfolio

This repository contains three aviation data analytics projects demonstrating skills in data cleaning, exploratory data analysis (EDA), dashboard development, machine learning, and geospatial visualization using real-world aviation datasets.

These projects were built as part of my data analytics portfolio to apply Python, SQL, Excel, Power BI, and machine learning techniques to aviation operations and performance analysis.

---

## Projects

### 1. Airline Delay Analysis Dashboard

**Objective**

Analyze airline operational performance and identify the major causes of flight delays through an interactive Power BI dashboard.

**Tools**

- Python
- Pandas
- Excel
- Power BI

**Highlights**

- Cleaned and prepared U.S. airline delay data covering 21 airlines.
- Performed exploratory data analysis to identify operational trends.
- Built an interactive Power BI dashboard with multiple KPI visualizations.
- Compared airline performance, on-time rates, and delay categories.

**Skills Demonstrated**

- Data Cleaning
- EDA
- KPI Reporting
- Dashboard Development
- Data Visualization

---

### 2. Flight Delay Prediction Model

**Objective**

Develop a machine learning model to predict whether a flight will arrive late based on operational flight information.

**Tools**

- Python
- Pandas
- Scikit-learn
- Matplotlib

**Highlights**

- Cleaned and transformed flight records into model-ready features.
- Performed feature engineering and preprocessing.
- Built a classification model to predict flight delays.
- Evaluated model performance using standard classification metrics.
- Identified important operational factors associated with flight delays.

**Skills Demonstrated**

- Data Preprocessing
- Feature Engineering
- Machine Learning
- Classification
- Model Evaluation

---

### 3. Live Aircraft Route Analysis

**Objective**

Visualize live aircraft movements across Asia using real-time flight data from the OpenSky API.

**Tools**

- Python
- Pandas
- Folium
- OpenSky API

**Highlights**

- Retrieved and processed more than 1,300 live aircraft records.
- Cleaned aircraft position, altitude, speed, and flight status data.
- Created an interactive map displaying aircraft locations.
- Analyzed regional traffic activity and aircraft movement patterns.

**Skills Demonstrated**

- API Data Collection
- Data Cleaning
- Geospatial Analysis
- Interactive Mapping
- Aviation Traffic Monitoring
